## Key Decisions

### Tool, Not Platform (March 2026)
**Decision:** TalentAgent is a candidate-side AI career tool, not a job board or LinkedIn competitor.

**Why:**
- LinkedIn has 1B users + 20 years of network effects — every competitor has failed
- Tools work for 1 user on day 1 — no chicken-and-egg problem
- Teal ($29/mo), Jobscan ($24/mo), Careerflow ($19/mo) prove the model — $750M market
- Our edge: honest fit scores + "Don't Apply" signals + ghost detection + AI agent

**Core Products:**
1. **Check My Fit** (top of funnel) — Free tool. Paste a job → get a score. Growth engine.
2. **AI Portfolio Agent** (depth) — Import resume → AI represents you. Monetization layer.
